# My Custom Agent («Моника»)

Модульный голосовой ассистент для управления Linux (Hyprland / Wayland) без использования нейросетевых языковых моделей (LLM). 

Обеспечивает моментальный отклик (<40 мс), нулевые затраты ресурсов, отсутствие лимитов на запросы (RPS) и 100% стабильность выполнения команд.

---

## Структура проекта

```text
my_custom_agent/
├── config.yaml              # Технические параметры (пути к Piper, голоса, каналы вывода)
├── character.yaml           # Личность: имя, фразы приветствия/успеха, вариации ответов
├── macros.yaml              # Макросы Hyprland (запуск программ по рабочим столам)
├── main.py                  # Главный скрипт и точка входа
├── core/
│   ├── engine.py            # Ядро маршрутизации команд и декоратор @skill
│   ├── persona.py           # Движок характера (рандомизация и персонализация реплик)
│   ├── mouth.py             # Синтез речи (Piper TTS) с мгновенным кэшированием WAV
│   ├── display.py           # Вывод уведомлений (notify-send, консоль, сокет Waifuland)
│   └── ears.py              # Распознавание речи через Faster-Whisper
├── skills/                  # Каталог плагинов (все файлы загружаются автоматически)
│   ├── workspace_macros.py  # Автоматический запуск сценариев из macros.yaml
│   ├── hyprland_control.py  # Управление окнами (fullscreen, floating, killactive, воркспейсы)
│   ├── media_control.py     # Громкость звука через pamixer и управление плеером
│   ├── system_info.py       # Время, дата, свободное место на диске и ОЗУ
│   └── web_scraper.py       # Шаблон скилла для парсинга любых сайтов
└── systemd/
    └── my_custom_agent.service # Файл службы для фонового автозапуска
```

## Режимы запуска

### 1. Интерактивный режим (для тестирования и отладки)
Позволяет вводить команды текстом с клавиатуры. Piper сразу озвучит результат, а система покажет уведомление:
```bash
python3 /home/armen/my_custom_agent/main.py
```

Примеры команд для ввода в консоль:
* `рабочий режим` — запустит приложения по воркспейсам согласно `macros.yaml`.
* `сделай громче` или `громкость 50` — изменит громкость через `pamixer`.
* `сколько времени` или `свободное место` — сообщит системную информацию.
* `проверь сайт` — выполнит веб-парсинг.

### 2. Одиночное выполнение команды (для хоткеев и hyprwhspr)
Идеально подходит для привязки к горячим клавишам или интеграции с внешними утилитами диктовки:
```bash
python3 /home/armen/my_custom_agent/main.py --exec "рабочий режим"
```

Привязка в конфиге Hyprland (`~/.config/hypr/bindings.conf` или `.lua`):
```ini
bind = $mainMod, F1, exec, python3 /home/armen/my_custom_agent/main.py --exec "рабочий режим"
bind = $mainMod, F2, exec, python3 /home/armen/my_custom_agent/main.py --exec "режим отдыха"
```

### 3. Режим прослушивания микрофона
Слушает микрофон и транскрибирует речь через локальный Faster-Whisper (CUDA на RTX 4060):
```bash
python3 /home/armen/my_custom_agent/main.py --listen
```

## Настройка характера и вывода

* **Смена голоса и скорости**: в файле `config.yaml` в секции `tts`. Достаточно указать путь к любой другой ONNX-модели Piper.
* **Смена характера и реплик**: в файле `character.yaml`. Добавляйте свои варианты фраз в списки `on_wake`, `on_success`, `on_error`. Ассистент будет выбирать их случайно, создавая эффект живой речи.
* **Каналы вывода**: в `config.yaml` можно отдельно выключать/включать голос, всплывающие уведомления `notify-send` или мост к `Waifuland`.

## Как добавлять новые макросы без программирования

Откройте `macros.yaml` и добавьте свой блок:
```yaml
macros:
  "мой режим":
    reply: "Включаю мой персональный режим"
    actions:
      - "hyprctl dispatch exec [workspace 1] zen-browser"
      - "hyprctl dispatch exec [workspace 2] alacritty"
```
После сохранения фраза *«Моника, мой режим»* сразу станет доступна!

## Как писать свои скиллы на Python

Создайте файл `skills/my_skill.py`:
```python
import subprocess
from core.engine import skill

@skill(
    name="my_action",
    triggers=["сделай действие", "запусти тест"],
    description="Описание того, что делает этот навык"
)
def handle_action(text: str, context: dict) -> str:
    # Здесь любой ваш код на Python
    # subprocess.run(...) или парсинг
    return "Действие успешно выполнено!"
```
При следующем запуске `main.py` скилл загрузится автоматически.
