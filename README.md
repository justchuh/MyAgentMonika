# ZeroVoiceAgent («Моника»)

Модульный, полностью локальный и приватный голосовой ассистент для Linux (Hyprland / Wayland / Omarchy) без использования нейросетевых языковых моделей (LLM).

Обеспечивает моментальный отклик (<40–120 мс), нулевые затраты ресурсов, 100% приватность (без отправки голоса в облако) и детерминированную надежность выполнения команд.

## Режимы запуска и консольное управление (`zerovoice`)

В системе установлена единая консольная утилита **`zerovoice`**.

### 1. Интерактивный режим (для тестирования текстом)
Позволяет вводить любые команды текстом с клавиатуры:
```bash
zerovoice
```

### 2. Режим непрерывного прослушивания микрофона
Активирует бесшовный режим One-Shot (Silero VAD + Faster-Whisper) с выводом логов в терминал:
```bash
zerovoice --listen
```

### 3. Одиночное выполнение команды (для хоткеев и скриптов)
Мгновенно выполняет действие, озвучивает ответ и сразу завершает работу:
```bash
zerovoice --exec "сколько времени"
zerovoice --exec "открой яндекс музыку"
zerovoice --exec "хочу кодить"
zerovoice --exec "закрой режим разработки"
```

### 4. Тихий фоновый переключатель (`toggle`)
Включает или выключает ассистента в фоне без открытия окон терминала:
```bash
zerovoice toggle
```

### 5. Проверка статуса фонового процесса
```bash
zerovoice status
```

### 6. Принудительный выбор голоса
```bash
# Легкий чистый голос Silero TTS (0% нагрузки на VRAM, быстрый запуск на CPU):
zerovoice --voice baya --listen

# Выполнить команду легким голосом:
zerovoice --voice baya --exec "сколько времени"
```

## Горячие клавиши в системе

Сама программа не захватывает клавиатуру напрямую — это задача оконного менеджера. В вашей системе **Omarchy / Hyprland** вызов привязан в конфигурационном файле `~/.config/hypr/bindings.lua`:

```lua
-- Тихий фоновый переключатель ZeroVoiceAgent
hl.unbind("SUPER + Q")
o.bind("SUPER + Q", "ZeroVoiceAgent toggle", "zerovoice toggle")
```

При нажатии **`Win + Q`** вызывается команда `zerovoice toggle`: в фоне тихо стартует или останавливается ассистент с выводом экранных уведомлений (`notify-send`). При желании вы можете привязать эту команду на любую другую комбинацию клавиш.

## Перенос на слабый ПК / Ноутбук (без дискретной видеокарты)

Если у вас слабый ноутбук или ПК без дискретной видеокарты NVIDIA, измените **всего два параметра** в файле `config.yaml`:

1. В секции `stt`:
   ```yaml
   stt:
     device: "cpu"         # Вместо "cuda"
     model: "small"        # Вместо "large-v3-turbo" (или "base" для максимальной легкости)
   ```
2. В секции `tts`:
   ```yaml
   tts:
     active_preset: "baya" # Вместо "nyamura_warm" (отключает RVC, чистый Silero на CPU)
   ```

*Потребление оперативной памяти снизится до ~400 МБ, нагрузка на видеопамять = 0%, а генерация речи займет всего 90 мс на обычном процессоре.*

## Как добавлять собственные скиллы

Чтобы добавить новую голосовую функцию, создайте файл `skills/my_skill.py`:

```python
from core.engine import skill

@skill(
    name="my_action",
    triggers=["сделай действие", "запусти тест", "мое действие"],
    description="Описание того, что делает этот навык"
)
def handle_action(text: str, context: dict) -> dict:
    # Здесь любой ваш код на Python
    return {
        "reply": "Действие успешно выполнено!",
        "emotion": "happy"
    }
```
При следующем запуске `zerovoice` скилл подхватится автоматически. Проверить его работу можно командой:
```bash
zerovoice --exec "сделай действие"
```

## Управление Запретом (Zapret) вручную

* Проверить статус процесса: `pgrep -fa nfqws`
* Принудительно остановить: `sudo pkill -f nfqws` (или `sudo bash ~/zapret-discord-youtube-linux/service.sh kill`)
* Запустить вручную: `cd ~/zapret-discord-youtube-linux && sudo bash service.sh run --config conf.env`
